# v0.0.22

와이파이에서만 업데이트를 받을 수 있는 옵션을 추가했어요.

## 새 기능

- **업데이트 다운로드를 Wi-Fi에서만 받도록 설정할 수 있어요**: 설정에서 "Wi-Fi 전용 다운로드"를 켜면 모바일 데이터로 업데이트 APK가 자동으로 받아지지 않아요. Wi-Fi가 아닐 때 다운로드를 시도하면 안내 문구가 떠요.

## 개선

- 위 옵션을 켜면 업데이트가 있는지 확인하는 것도 Wi-Fi에 연결됐을 때만 하도록 고쳤어요. 모바일 데이터로 쓰다가 Wi-Fi에 연결하면 앱을 다시 켤 때 바로 업데이트를 확인해요.

## 업스트림 동기화

- 덱 위젯의 카드 수 표시 정렬을 다듬었어요.
- 번역이 최신화됐어요.
