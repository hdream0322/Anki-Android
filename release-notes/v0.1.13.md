# v0.1.13

AI 모델을 고를 때 어떤 모델이 빠르고 저렴한지, 어떤 모델이 똑똑한지 한눈에 볼 수 있어요. ChatGPT·Claude·Gemini API 키도 각각 따로 저장돼요.

## 새 기능

- **모델 등급 한눈에 보기**: 설정 → 유용한 기능 → AI → 모델 목록에서 모델마다 "빠름·저렴", "균형", "고성능" 등급과 한 번에 읽을 수 있는 글의 양이 함께 나와요.
- **모델 자세히 보기**: 목록에서 모델을 길게 누르면 비용, 성능, 어떤 질문에 쓰면 좋은지와 모델 사양을 볼 수 있어요. 이 창에서 바로 그 모델을 고르거나, 공식 가격표를 열어 정확한 가격을 확인할 수 있어요.
- **AI마다 API 키 따로 저장**: ChatGPT·Claude·Gemini 키를 각각 저장해 두고, 제공자만 바꿔 가며 쓸 수 있어요. 예전에 넣어 둔 키는 그때 쓰던 제공자의 키로 그대로 옮겨져요.

## 개선

- 오래된 ChatGPT 모델은 목록 아래쪽에 모여서 최신 모델을 찾기 쉬워졌어요.
