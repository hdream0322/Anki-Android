# v0.1.0

복습 화면에서 카드 내용을 두고 AI에게 바로 질문할 수 있는 기능이 생겼어요. 화이트보드 관련 개선과 업스트림 변경사항도 함께 반영했어요.

## 새 기능

- **AI 카드 채팅**: 복습 화면에서 지금 보고 있는 카드에 대해 AI에게 바로 물어볼 수 있어요. 헷갈리는 내용을 설명받거나 예문을 물어볼 때 쓰면 좋아요. ChatGPT·Claude·Gemini 중 원하는 걸 골라 쓰고, 사용하려면 해당 서비스의 키가 필요해요. 키는 이 기기에만 암호화해서 저장돼요.
- **화이트보드 그림 복구**: 학습을 취소하면 이전 카드에 그려뒀던 화이트보드 그림도 같이 되살아나요.
- **더 안전해진 자동 업데이트**: 새 버전을 내려받은 뒤 파일이 손상되지 않았는지 확인하고 설치해요.

## 버그 수정

- 무음 시작 모드가 풀렸을 때 안내가 시스템 알림 대신 앱 안쪽 메시지로 표시돼요.
- AI 채팅이 일시적으로 실패하면 자동으로 다시 시도하고, 오류 메시지도 더 알기 쉽게 바꿨어요.

## 업스트림 동기화

- 알림 리마인더, 프로필 관리, 애드온 검증 등 최신 upstream 변경사항을 반영했어요.
- 번역이 최신화됐어요.
