# v0.1.4

학습 화면 진행률 바에 반짝임 효과를 더했고, 앱 업데이트를 받을 때 진행 상황을 더 자세히 볼 수 있어요.

## 새 기능

- **진행률 바 반짝임 효과**: 학습 중 상단 진행률 바의 채워진 부분 위로 빛이 왼쪽에서 오른쪽으로 지나가요. 설정 → 유용한 기능 → 리뷰어 → "진행률 바 반짝임 효과"에서 켜고 끌 수 있어요.
- **자세한 업데이트 다운로드 화면**: 새 버전을 받는 동안 어떤 버전에서 어떤 버전으로 바뀌는지, 지금 어느 단계인지(연결 중·다운로드 중·파일 확인 중), 받은 용량과 전체 용량, 속도와 남은 시간을 보여줘요. 알림에서도 같은 내용을 볼 수 있어요.

## 개선

- 업데이트 확인·다운로드 결과 안내가 앱 화면 아래쪽에 앱 스타일 알림으로 떠요.
