# v0.1.18

최신 AnkiDroid 변경사항을 반영했어요. 프로필 관리, 노트 편집기 툴바, 이미지 편집 등 새 기능이 들어왔고, 여러 화면의 안정성이 좋아졌어요.

## 새 기능

- **프로필 이름 변경·추가**: 프로필 전환 화면에서 바로 새 프로필을 만들고, 기존 프로필 이름을 바꿀 수 있어요.
- **노트 편집기 툴바 배치 선택**: 노트 편집기의 서식 툴바를 원하는 배치로 고를 수 있어요.
- **외부 앱으로 이미지 편집**: 노트에 넣을 이미지를 다른 사진 편집 앱으로 열어 고칠 수 있어요.
- **카드 유형 순서 변경**: 카드 템플릿 편집에서 카드 유형의 순서를 바꿀 수 있어요.
- **새 타임박스 설정 화면**: 학습 시간 제한 설정이 더 보기 쉬운 화면으로 바뀌었어요.
- 하단 메뉴가 화면을 스크롤하면 자동으로 숨겨져 더 넓게 볼 수 있어요.
- 음성 읽기 엔진이 설치돼 있지 않으면 안내 창을 보여줘요.

## 버그 수정

- 노트 편집 중 노트 유형을 바꾸거나 다른 앱을 쓰다 돌아왔을 때 입력한 내용이 사라지던 문제를 고쳤어요.
- 사용자 지정 학습 창이 느리게 열리거나, 화면을 돌린 뒤 선택한 태그·입력값이 사라지던 문제를 고쳤어요.
- 카드 템플릿 편집에서 카드 유형을 지울 때 잘못된 개수가 표시되거나 변경이 저장되지 않던 문제를 고쳤어요.
- 카드 목록에서 편집·검색 후 카드 개수가 제때 갱신되지 않던 문제를 고쳤어요.
- 공유 덱을 받을 때 AnkiWeb 로그인이 필요하면 로그인 화면을 안내하고, 다운로드가 거부돼도 앱이 꺼지지 않게 했어요.
- 미리보기에서 카드 앞뒤를 넘길 때 소리가 계속 나던 문제를 고쳤어요.
- 백그라운드 동기화가 중복으로 실행되거나 데이터 요금제 설정을 무시하던 문제를 고쳤어요.

## 업스트림 동기화
