# v0.1.20

덱 목록의 스크롤 위치 유지를 설정에서 켜고 끌 수 있게 됐고, 최신 AnkiDroid 변경사항을 반영했어요.

## 새 기능

- **학습 후 스크롤 위치 유지 설정**: 설정 → 유용한 기능 → "덱 목록"에서 학습 날짜 순으로 정렬할 때 목록 위치를 그대로 둘지 고를 수 있어요. 기본값은 켜짐이에요.
- **공유로 추가할 때 덱 기억**: 다른 앱에서 AnkiDroid로 공유해 카드를 추가하면, 마지막으로 저장한 덱을 다음 공유 때도 그대로 골라 둬요. 평소 공부하는 덱 선택에는 영향이 없어요.

## 버그 수정

- 숨겨진 '기본' 덱을 공부하려고 하면 앱이 꺼지던 문제를 고쳤어요.
- 공유 덱 화면에서 AnkiWeb에 로그인한 뒤 보던 덱으로 돌아가지 않던 문제와, 뒤로 가기가 엉뚱하게 동작하던 문제를 고쳤어요.
- 권한 설정 화면에서 아이콘이 보이지 않던 문제를 고쳤어요.
- 프로필 이름 글자 수를 셀 때 앞뒤 공백까지 세던 문제를 고쳤어요.
- 블랙 테마에서 아래에서 올라오는 메뉴의 배경색이 어색하던 문제를 고쳤어요.

## 업스트림 동기화

- 최신 upstream 변경사항을 반영했어요.
- 설명 글처럼 흐리게 보이는 글자가 색이 들지 않은 회색으로 바뀌어 더 깔끔하게 보여요.
- 번역이 최신화됐어요.
