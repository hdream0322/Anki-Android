# v0.0.9

## 새 기능

- **덱 학습 완료 축하 파티클**: 덱 학습을 모두 끝내 "축하합니다! 오늘의 학습을 마쳤습니다" 화면이 나타날 때, (태블릿 분할 화면 등) 우측 패널 위로 색종이가 떨어지는 축하 효과가 재생됩니다.

## 개선

- **효과음 다듬기**
  - 덱 완료 박수 소리를 5초 → 3초로 짧게 조정했습니다.
  - 정답 효과음을 더 짧고 경쾌하게(앞뒤 공백 제거 + 1.5배속) 다듬었습니다.
  - '어려움' 버튼에도 정답 효과음이 재생됩니다.
  - 연속 실패 또는 leech 시 오답음과 낙담음이 동시에 재생되도록 했습니다.
- 효과음 설정 화면의 한글 번역을 추가했습니다.
