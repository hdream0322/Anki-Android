# v0.0.15

## 새 기능

- **화이트보드 확대/축소 동기화 옵션을 앱 설정에도 추가**: 이전엔 화이트보드 메뉴에서만 켜고 끌 수 있던 "카드와 함께 확대/축소" 옵션을 앱 설정에서도 바로 켜고 끌 수 있어요.
- **복습 알림 설정 접근성 개선**: 복습 알림 설정을 앱 설정뿐 아니라 덱 목록, 학습 화면에서도 바로 열 수 있게 했어요.

## 개선

- 덱 삭제 확인 대화상자의 버튼 문구를 "삭제"로 더 명확하게 바꿨어요.
- 학습 화면의 불필요한 구분선을 없애 화면을 더 깔끔하게 정리했어요.

## 버그 수정

- 화면을 회전해도 복습 알림 시간 선택기가 깨지지 않도록 고쳤어요.
- 문제 해결 화면에서 화면을 회전하면 앱이 죽던 오류를 수정했어요.
- 새 덱을 만들면 덱 목록에서 바로 선택되지 않던 문제를 고쳤어요.

## 업스트림 동기화

- AnkiDroid 최신 upstream 변경사항을 반영했어요.
