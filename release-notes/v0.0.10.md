# v0.0.10

## 새 기능

- **Appbar 카드 진행 현황 표시**: "예상 시간 표시" 설정이 켜진 경우, 남은 시간 옆에 오늘 처리한 카드 수와 총 카드 수가 `n분 남음(처리/총)` 형태로 함께 표시됩니다.
- **인앱 업데이트 개선**: 업데이트 다운로드 중 진행률이 실시간으로 표시되며, 릴리즈 노트가 마크다운으로 렌더링됩니다.

## 버그 수정

- **효과음 씹힘 방지**: 짧은 효과음이 겹쳐 재생될 때 소리가 끊기던 문제를 SoundPool 전환으로 해결했습니다.
- **효과음 중복 재생 방지**: 덱 학습 완료 시 정답 효과음과 박수 소리가 동시에 재생되던 문제를 수정했습니다.

## 업스트림 동기화

- AnkiDroid 최신 upstream 변경사항을 반영했습니다 (Navigation 아키텍처 개선, 카드 브라우저 딥링크 수정, 스타트업 프로파일링 등).
