# v0.1.10

최신 AnkiDroid 변경사항을 반영한 버전이에요. 공유 덱 다운로드 화면이 새로워지고, 화이트보드와 태그 편집이 더 편해졌어요.

## 새 기능

- **공유 덱 다운로드 화면 개선**: 덱을 내려받을 때 다운로드 속도와 남은 시간이 보여요.
- **스타일러스 버튼으로 지우개 전환**: 화이트보드에서 펜의 버튼을 누르면 지우개로 바뀌어요.
- **컬렉션이 잠겼을 때 안내 강화**: 컬렉션을 열 수 없다는 창에서 바로 설정으로 갈 수 있고, 'Anki가 이미 열려 있음' 오류가 왜 생겼는지 설명해 줘요.

## 버그 수정

- 화이트보드에서 기기를 흔드는 동작이 아무 반응도 없던 문제를 고쳤어요.
- 덱 목록 위젯에서 글자가 잘리던 문제를 고쳤어요. 글자 크기에 맞춰 줄 높이가 바뀌고, 줄 어디를 눌러도 열려요.
- 태그 편집에서 키보드가 태그 목록을 가리거나, 가로 화면에서 태그 검색이 멈추던 문제를 고쳤어요. 상위 태그의 선택 상태가 잘못 보이던 문제도 고쳤어요.
- 동기화가 끝날 무렵이나 오래 걸릴 때 앱이 꺼지던 문제를 고쳤어요.
- 카드의 수식 글자 크기가 화면 설정과 맞지 않던 문제를 고쳤어요.
- 노트 편집 중 노트 유형을 바꾸면 저장하지 않은 내용에 대한 경고 없이 사라지던 문제를 고쳤어요.
- 미디어 검사에서 문제가 생기면 앱이 꺼지는 대신 오류 내용을 보여 줘요.

## 업스트림 동기화

- 최신 upstream 변경사항을 반영했어요.
- 번역이 최신화됐어요.
