# v0.0.3 — 자동 업데이트와 잔디밭 위젯

이번 빌드부터 GitHub에 새 버전이 올라오면 앱이 알아서 알려주고, 한 번 탭만으로 업데이트할 수 있어요.

## 새 기능
- **인앱 자동 업데이트**: 앱 시작 시 GitHub 릴리스를 확인해 새 버전이 있으면 다운로드 → 설치 prompt로 안내합니다. 다운로드는 알림 표시줄에서 진행률을 볼 수 있어요.
- **리뷰 히트맵 위젯**: 홈 화면에 잔디밭 위젯을 추가할 수 있습니다. 위젯 추가 시 보여 줄 덱을 선택하세요.
- **태블릿 분할 화면 개선**: 학습을 모두 끝낸 덱을 골라도 우측 패널이 비지 않고 카드 통계와 함께 🎉 축하 문구를 보여 줍니다.

## 다듬은 부분
- **설정 → 일반 → Deurim**에 "지금 업데이트 확인" 항목을 추가했습니다. About 화면에서도 같은 버튼을 누를 수 있어요.
- 디버그/릴리스 모두 런처 라벨이 `AnkiDroid.d` 로 통일됐습니다 (디버그는 빨간 아이콘으로 구분).
- About 화면 버전 줄을 `2.24.0+0.0.3 (22400303)` 형식으로, 날짜는 실제 릴리스 시각으로 표시합니다.
- 덱 리스트에서 덱을 바꿀 때 우측 패널이 깜빡이던 현상을 고쳤습니다.

## 알아 둘 것
- 자동 업데이트는 24시간에 한 번 백그라운드로 확인합니다. 즉시 보려면 설정/About에서 "지금 업데이트 확인"을 누르세요.
- 처음 업데이트할 땐 안드로이드가 "알 수 없는 출처" 권한을 한 번 요구할 수 있습니다.
