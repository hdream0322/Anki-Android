# v0.1.21

복습할 카드가 없던 날에도 연속 학습 기록이 끊기지 않게 됐고, 최신 AnkiDroid 변경사항을 반영했어요.

## 새 기능

- **쉬는 날에도 연속 기록 유지**: 복습할 카드가 하나도 없어서 공부하지 않은 날은 '쉬는 날'로 처리돼요. 연속 학습 일수가 끊기지도, 늘어나지도 않아요. 히트맵과 위젯에서 초록색 테두리로 표시되고, 눌러 보면 "복습할 카드 없음 · 연속 유지"라고 알려 줘요.
- 필터 덱에 들어가 있는 카드의 복습 횟수도 원래 덱의 히트맵에 함께 집계돼요.

## 버그 수정

- 덱 파일(.apkg)을 다른 앱에서 열거나 공유로 가져올 때, 덱이 아닌 텍스트 파일로 잘못 인식돼 가져오기에 실패하던 문제를 고쳤어요.
- 카드 탐색기에서 긴 내용이나 저장된 검색을 볼 때 화면이 멈추던 문제를 고쳤어요.
- 태그 목록에서 검색할 때 하위 태그가 저절로 펼쳐지거나, 접기·펼치기가 엉뚱하게 동작하던 문제를 고쳤어요.
- 태그 이름의 대소문자만 바꿔 이름을 변경할 때 제대로 반영되지 않던 문제를 고쳤어요.
- 빠른 카드 편집 화면에서 저장을 연달아 누르면 두 번 저장되던 문제를 고쳤어요.
- 일부 입력 창에서 버튼이 화면 밖으로 밀려 보이지 않던 문제와, 팝업 메뉴 뒤가 비쳐 보이던 문제를 고쳤어요.
- 입력 창에서 글자를 고치는 도중 커서 위치나 선택 영역이 풀리던 문제를 고쳤어요.

## 업스트림 동기화
