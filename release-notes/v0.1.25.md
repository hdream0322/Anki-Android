# v0.1.25

최신 AnkiDroid 변경사항을 반영한 버전이에요. AI 채팅 기본 모델이 새 Gemini로 바뀌었고, 덱 목록과 브라우저의 불안정한 부분들을 많이 고쳤어요.

## 새 기능

- **AI 채팅 기본 모델 변경**: Gemini의 기본 모델이 최신 모델인 Gemini 4 Hydrogen으로 바뀌었어요. 설정에서 직접 고른 모델은 그대로 유지돼요.
- **정답 버튼 색을 테마에 맞추기**: 복습 설정에서 정답 버튼 색을 앱 테마 색으로 맞출 수 있어요. 정답 버튼 설정 화면도 새로 정리됐어요.
- **브라우저 검색 도구에 필터 칩**: 검색 도구에서 칩을 눌러 빠르게 조건을 걸 수 있어요.
- **노트 편집기에서 바로 녹음**: 노트를 편집하다가 그 자리에서 음성을 녹음해 넣을 수 있어요.
- **프로필 바로 전환**: 프로필 목록에서 원하는 프로필로 바로 전환할 수 있어요.
- **컬렉션 점검 안내**: 컬렉션이 어긋나 있으면 데이터베이스 점검을 해 보라고 안내해 줘요.
- **공유 덱 다운로드 표시**: 다운로드가 시작되기 전에도 진행 중이라는 표시가 나오고, 진행 막대가 부드럽게 움직여요.

## 버그 수정

- 덱 목록에서 덱을 빠르게 연달아 누르거나 화면을 돌린 뒤에도 스크롤 위치가 엉키지 않도록 고쳤어요.
- 덱 목록이나 빈 카드 정리에서 오류가 났을 때 앱이 꺼지지 않고 오류 내용을 보여 줘요.
- 브라우저에서 검색이 끝나지 않거나, 검색 기록이 실패한 검색까지 저장되던 문제를 고쳤어요. 검색에 실패하면 다시 시도할 수 있어요.
- 태그를 붙여 넣거나 일본어 입력기로 입력할 때 공백이 이상하게 처리되던 문제를 고쳤어요.
- 노트 편집기에서 이미지를 붙여 넣을 때 움직이는 이미지가 멈추거나, 저장 중에 저장을 다시 눌러 문제가 생기던 부분을 고쳤어요.
- 공유 덱을 받는 중에 뒤로 가기를 누르면 확인을 먼저 물어봐요.
- 홈 화면 위젯의 빈 화면 표시가 잘리던 문제를 고쳤어요.
- 사용자 지정 학습에서 이름이 "filtered"인 덱을 고르면 잘못된 항목이 켜지던 문제를 고쳤어요.
