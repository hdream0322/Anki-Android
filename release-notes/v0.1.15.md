# v0.1.15

AI 채팅 답변이 훨씬 보기 좋아졌어요. 굵은 글씨, 목록, 표가 그대로 보이고 수학 수식도 깔끔하게 표시돼요.

## 새 기능

- **AI 답변 서식 표시**: AI 답변의 굵은 글씨, 기울임, 목록, 표, 취소선, 코드가 기호 그대로가 아니라 서식이 적용된 모습으로 보여요.
- **수식 표시**: AI가 답변에 쓴 수학 수식이 교과서처럼 렌더링돼서 보여요. 인터넷이 없어도 표시돼요.

## 버그 수정

- 카드 속 웹 링크가 열리지 않거나, 링크를 열 수 없을 때 앱이 멈추던 문제를 고쳤어요.
- 덱 목록에서 + 버튼 메뉴를 연 뒤 바깥을 눌러도 닫히지 않던 문제를 고쳤어요.
- 음성 읽기(TTS)가 기본 음성 엔진의 목소리를 우선 사용하도록 고쳤어요.
- 노트 편집기에서 사진을 붙여 넣을 때 파일 이름이 잘못 저장되던 문제를 고쳤어요.
- 노트 편집기에서 갤러리를 열었다가 취소하면 화면이 깜박이던 문제를 고쳤어요.
- 녹음 파일이 사라지거나 오래된 녹음이 저장 공간을 계속 차지하던 문제를 고쳤어요.
- 데이터 요금제 연결에서 동기화 제한 설정이 미디어 파일에는 적용되지 않던 문제를 고쳤어요.
- 카드 유형을 새로 만들 때 생성될 카드 수가 잘못 표시되던 문제를 고쳤어요.

## 업스트림 동기화

- 최신 upstream 변경사항을 반영했어요.
- 번역이 최신화됐어요.
