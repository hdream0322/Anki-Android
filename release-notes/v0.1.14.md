# v0.1.14

AI 채팅이 더 친절해졌어요. 오류가 나면 이유와 해결 방법을 알려 주고, 버튼 하나로 같은 질문을 다시 보낼 수 있어요. 학습 화면에서는 오늘 얼마나 공부했는지 퍼센트로 볼 수 있어요.

## 새 기능

- **AI 채팅 다시 시도**: 답변을 받지 못한 질문 아래에 "다시 시도" 버튼이 생겨요. 질문을 다시 입력하지 않아도 같은 내용으로 한 번 더 물어볼 수 있어요.
- **AI 오류 안내 개선**: 인터넷 끊김, 응답 지연, API 키 오류, 크레딧 부족, 요청 한도 초과, 대화가 너무 긴 경우 등 상황마다 무엇이 문제인지와 어떻게 하면 되는지 알려 줘요. "자세히"를 누르면 AI 서비스가 보낸 원래 오류 내용도 볼 수 있어요.
- **AI 답변은 항상 한국어로**: 카드가 외국어로 되어 있어도 AI가 한국어로 답해요.
- **학습률 표시**: 학습 화면 위쪽에 남은 시간, 학습한 카드 수와 함께 오늘 학습률(%)이 나와요.
- **진행률 바 끄기**: 설정 → 유용한 기능에서 학습 화면의 진행률 바를 숨길 수 있어요.

## 개선

- AI 답변을 기다리는 동안 "답변 생성 중..." 점이 움직여서 요청이 진행 중인지 알 수 있어요.
- AI에 카드 앞면 내용을 두 번 보내지 않아 API 사용량이 조금 줄었어요.
- AI 제공자를 바꿔도 제공자마다 골라 둔 모델이 그대로 유지돼요. 고른 모델이 더 이상 제공되지 않으면 기본 모델로 바꾸고 알려 줘요.

## 버그 수정

- 덱을 삭제하면 선택해 둔 다른 덱 선택이 풀리던 문제를 고쳤어요.
- 이름이 빈칸뿐인 하위 덱이 만들어지던 문제를 고쳤어요.
- 카드 입력칸 자동 포커스 끄기 설정이 제대로 동작하지 않던 문제를 고쳤어요.
- 공유 덱을 받다가 요청이 많아 막히면 AnkiWeb 로그인 화면으로 안내하도록 고쳤어요.
- 저장소 권한을 허용한 뒤 노트 추가 위젯이 바로 갱신되지 않던 문제를 고쳤어요.
- 일부 기기에서 위젯(잔디밭 위젯 포함) 때문에 앱이 튕기던 문제를 고쳤어요.

## 업스트림 동기화

- 번역이 최신화됐어요.
