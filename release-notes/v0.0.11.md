# v0.0.11

## 버그 수정

- **Progress bar 애니메이션 개선**: 앱바의 카드 진행 progress bar가 부드럽게 애니메이션되며, 롤오버 시각 설정이 실시간으로 반영됩니다.
- **Progress bar 리셋 버그 수정**: 학습 화면을 벗어났다가 다시 진입할 때 progress bar가 0으로 초기화되던 문제를 수정했습니다.
- **효과음 무음 버그 수정**: 특정 상황에서 효과음이 재생되지 않던 문제를 수정했습니다.
- **잔디밭 날짜 기준 수정**: 히트맵의 하루 경계가 자정 대신 Anki 롤오버 시각(기본 새벽 4시)을 기준으로 정확하게 계산됩니다.

## 업스트림 동기화

- AnkiDroid 최신 upstream 변경사항을 반영했습니다 (`dir="auto"` 카드 방향 안정화, 비제한 코루틴 스코프 수명주기 연동 리팩터링 등).
