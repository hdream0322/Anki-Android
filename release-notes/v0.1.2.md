# v0.1.2

앱 전체 색상이 새 앱 아이콘과 어울리는 주황색으로 바뀌었어요. 화면 배치와 사용법은 그대로이고 색만 달라졌어요. 최신 upstream의 안정성 개선도 함께 반영했어요.

## 새 기능

- **주황색 테마**: 상단 바, 버튼, 강조 표시, 로고 등 파란색이던 부분이 주황색으로 바뀌었어요. 라이트·다크·블랙 테마 모두 적용돼요. '다시'·'쉬움' 같은 답 버튼이나 새 카드 수처럼 의미가 있는 색은 익숙하게 쓰실 수 있도록 그대로 두었어요.
- **동기화 표시가 더 잘 보여요**: 덱 목록 상단의 동기화 아이콘에 표시되는 알림 점이 주황색 바 위에서도 잘 보이도록 색을 바꿨어요.

## 버그 수정

- 다른 앱을 한참 쓰다가 돌아왔을 때 복습 화면이나 카드 목록이 멈추거나 튕기던 문제를 고쳤어요.
- 카드 화면이 갑자기 하얗게 비거나 멈추던 문제가 줄어들었어요.
- 공유 덱 다운로드가 실패했을 때 다시 시도할 수 있어요.
- 덱 가져오기에 실패하면 안내 창이 바로 사라지지 않고 확인할 때까지 남아 있어요.
- 덱 목록에서 검색 중에 검색창이 닫히던 문제를 고쳤어요.
- 카드 템플릿 편집 화면에서 키보드가 내용을 가리던 문제를 고쳤어요.
- 버튼을 여러 번 눌렀을 때 같은 창이 겹쳐 뜨던 문제를 고쳤어요.

## 업스트림 동기화

- 번역이 최신화됐어요.
