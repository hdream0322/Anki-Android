# v0.1.22

AI 채팅에 보낼 지시문을 직접 고칠 수 있게 됐고, 카드 학습 기록까지 참고하는 더 똑똑한 AI 튜터가 됐어요.

## 새 기능

- **AI 시스템 프롬프트 직접 수정**: 설정 → 유용한 기능 → AI → 시스템 프롬프트에서 AI에게 매번 전달되는 지시문을 바꿀 수 있어요. 기본 지시문은 카드 공부에 맞게 최적화되어 있어서 대부분은 그대로 쓰는 게 가장 좋지만, 원하는 말투나 방식이 있다면 필요한 부분만 고쳐 보세요. "시스템 프롬프트 초기화"를 누르면 언제든 기본값으로 돌아가요.
- **더 똑똑해진 AI 튜터**: 아직 정답을 보지 않은 상태에서 채팅을 열면, AI가 답을 바로 알려 주지 않고 스스로 떠올릴 수 있게 힌트를 줘요. 답을 직접 물어보면 그때 알려 줘요.
- AI가 카드의 덱 이름과 태그도 함께 보고, 과목에 맞게 설명해 줘요. 휴대폰 화면에 맞게 짧게 답하고, 외우기 쉬운 연상법이나 예문을 곁들여 줘요.
- 카드 내용이 틀렸거나 애매해 보이면 AI가 알려 주고 올바른 내용을 제안해 줘요.
- **카드 학습 정보 함께 보내기**: 설정에서 켜면 그 카드를 몇 번 복습했고 몇 번 틀렸는지, 다음 복습까지 간격, 기억 확률 같은 정보도 AI에게 함께 전달돼요. 자주 틀리는 카드라면 AI가 더 기억에 남는 방법으로 설명해 줘요. 기본은 꺼져 있어요.

## 버그 수정

- 학습·미리보기 화면을 닫을 때 생길 수 있던 오류를 수정했어요.
- 기기를 켠 직후처럼 저장소가 늦게 준비될 때, 홈 화면 위젯을 갱신하다 앱이 응답하지 않던 문제를 고쳤어요.
- 덱 학습 옵션 창의 다시 만들기·비우기·묻어 둔 카드 꺼내기가 화면에 보이는 덱이 아닌 다른 덱에 적용될 수 있던 문제를 고쳤어요.
- 일부 휴대폰에서 기기 저장소의 파일을 골라 가져오기에 실패하던 문제를 고쳤어요.
- 복습 알림을 '오늘 복습하지 않았을 때만' 받도록 해 두었는데, 하위 덱이나 필터 덱에서 공부한 건 세지 않아 이미 공부한 날에도 알림이 오던 문제를 고쳤어요.
