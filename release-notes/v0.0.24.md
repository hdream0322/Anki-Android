# v0.0.24

앱을 열자마자 효과음이 갑자기 크게 나서 놀라는 문제를 해결했어요. 업스트림 변경사항도 여러 개 반영했어요.

## 새 기능

- **효과음이 갑자기 크게 나서 놀라는 일이 없어졌어요**: 이제 앱을 새로 열면 정답·오답·박수 같은 효과음이 무음 상태로 시작해요. 미디어 볼륨을 직접 조절하면(예: 볼륨 버튼) 그 순간부터 "소리를 듣고 싶다"는 뜻으로 보고 효과음이 정상적으로 재생돼요. 볼륨을 건드리지 않으면 계속 무음이라, 미디어 볼륨이 크게 설정돼 있어도 더 이상 갑자기 놀랄 일이 없어요.

## 업스트림 동기화

AnkiDroid 최신 upstream 변경사항을 반영했어요. 눈에 띄는 것들:

- 카드 브라우저의 정렬 방식을 고르는 화면이 새로워졌고(알약 버튼 + 시트), 정렬을 바꾸면 스낵바로 안내해줘요. 화면 디자인도 엣지 투 엣지로 다듬었어요.
- 덱 목록 하단 내비게이션에 키보드 단축키가 생겼고, 하위 덱 구조가 트리 모양 선으로 표시돼요.
- 미디어 동기화가 실패했을 때 뜨는 알림을 펼쳐서 자세히 보고, 내용을 복사할 수 있어요.
- 여러 카드의 마감일을 한 번에 설정할 때 가끔 나던 크래시를 고쳤어요.
- 프리뷰어(미리보기) 화면을 다크 모드에서 열었을 때 배경색이 잘못 나오던 문제를 고쳤어요.
- 필터링된 덱 화면이 회전 등으로 다시 그려져도 이전 상태가 유지돼요.
- 발음 확인 버튼과 카드 브라우저 필터 체크박스에 스크린 리더용 설명이 추가됐어요.
- 번역이 최신화됐어요.
