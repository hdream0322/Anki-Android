# v0.1.7

덱 목록에서 덱마다 파스텔 색을 칠해 원하는 덱을 한눈에 찾을 수 있어요. 최신 AnkiDroid의 개선 사항도 함께 반영했어요.

## 새 기능

- **덱 색상**: 덱 선택 화면에서 덱을 길게 누르고 '덱 색상'을 고르면 분홍 / 복숭아 / 레몬 / 민트 / 하늘 중 하나로 덱 줄을 칠할 수 있어요. '색 없음'을 고르면 원래대로 돌아가요. 색은 이 기기에만 저장되고, 야간 테마에서는 같은 계열의 어두운 색으로 보여요.
- **접힌 덱에 하위 덱 색 표시**: 상위 덱을 접어 두면 안에 있는 하위 덱들의 색이 덱 이름 옆에 작은 점으로 보여요. 펼치면 점은 사라져요.

## 버그 수정

- 카드를 뒤집을 때 스크롤 위치가 맨 위로 돌아가던 문제를 고쳤어요.
- 카드를 묻어 두고 다음 카드로 넘어가도 이전 카드의 확대 상태가 그대로 남던 문제를 고쳤어요.
- 카드 브라우저에서 열 순서를 바꾸자마자 스크롤하면 앱이 꺼지던 문제를 고쳤어요.
- 카드 브라우저에서 화면을 돌리면 카드 개수 표시가 사라지던 문제를 고쳤어요.
- 덱 옵션에서 프리셋을 최적화한 뒤 오류 창이 떠서 화면을 쓸 수 없던 문제를 고쳤어요.
- 카메라 앱이 없는 기기에서 노트 편집기와 이미지 가리기에 쓸 수 없는 카메라 버튼이 보이던 문제를 고쳤어요.
- FSRS를 쓰지 않을 때 필터 덱에서 FSRS 전용 정렬 방식이 보이던 문제를 고쳤어요.

## 업스트림 동기화

- 카드 브라우저에 기본 검색어를 지정할 수 있어요.
- 덱 옵션에서 프리셋 최적화를 한 뒤에도 옵션 화면이 닫히지 않아요.
- 복습 알림의 제목과 문구를 더 알아보기 쉽게 다듬었어요.
- 최신 upstream 변경사항을 반영했어요.
- 번역이 최신화됐어요.
