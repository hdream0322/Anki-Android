# v0.0.7

## 새 기능

- **태블릿 분할 화면 — 덱 이름 전체 표시**: 우측 패널 상단에 선택된 덱의 전체 이름이 보입니다. 긴 계층 덱(예: `1차 > 교육과정A > 국어 > 각론 > 듣기말하기`)도 줄임 없이 계층 구조를 파악할 수 있도록 표시합니다.
- **잔디밭 위젯 탭 → 해당 덱 바로 선택**: 홈 화면의 잔디밭 위젯을 탭하면 앱이 열리면서 위젯에 설정된 덱이 덱 목록에서 자동으로 선택됩니다.
- **화이트보드 선 굵기 ± 버튼**: 화이트보드 선 굵기 다이얼로그에 − / + 버튼이 생겨 한 번씩 눌러 조절할 수 있습니다.
- **화이트보드 설정 덱 간 공유 옵션**: 화이트보드 설정(색상·굵기 등)을 모든 덱에서 공유할지, 덱마다 독립적으로 유지할지 선택할 수 있습니다.

## 버그 수정

- **잔디밭 위젯 config 화면 재등장 버그 수정**: 위젯에서 덱을 선택한 뒤 앱 아이콘으로 재진입하면 config 화면이 다시 뜨던 문제를 수정했습니다.
- 업데이트 캐시에 오래된 APK가 남아 있을 때 다운로드가 실패하던 문제를 수정했습니다.
