# v0.1.12

AI 채팅에서 쓸 모델을 목록에서 골라 쓸 수 있어요. 최신 AnkiDroid의 개선 사항도 함께 반영했어요.

## 새 기능

- **AI 모델 고르기**: 설정 → 유용한 기능 → AI → 모델을 누르면, 내 API 키로 쓸 수 있는 ChatGPT·Claude·Gemini 모델 목록이 나와요. 원하는 모델을 누르기만 하면 돼요. 목록을 불러오지 못해도 기본 모델을 쓰거나 이름을 직접 입력할 수 있어요.
- **AI 기본 모델 최신화**: 모델을 따로 고르지 않았다면 Claude와 Gemini가 더 새로운 모델로 답해요.

## 버그 수정

- AI 제공자를 바꾸면 이전 제공자의 모델 이름이 그대로 남아 채팅이 실패하던 문제를 고쳤어요. 이제 제공자를 바꾸면 모델 설정이 기본값으로 돌아가요.
- API 키에 눈에 보이지 않는 문자가 섞여 붙여 넣어졌을 때, 키 내용이 오류 기록에 남을 수 있던 문제를 고쳤어요.

## 업스트림 동기화

- 화면을 돌리거나 다른 앱을 쓰다 돌아오면 덱 검색어가 사라지던 문제를 고쳤어요.
- 미디어 확인이나 저장 공간 부족 경고 창이 화면을 돌리면 사라지던 문제를 고쳤어요.
- 컬렉션이 너무 커서 동기화할 수 없을 때 나오는 안내를 더 알기 쉽게 바꿨어요.
- 덱 목록에서 노트 추가 화면을 열 때 + 버튼 메뉴가 열린 채로 남던 문제를 고쳤어요.
- 덱 목록 메뉴에서 앱이 갑자기 꺼지던 문제를 고쳤어요.
- 최신 upstream 변경사항을 반영했어요.
- 번역이 최신화됐어요.
