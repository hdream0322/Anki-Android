# v0.0.8

## 새 기능

- **학습 효과음**: 카드를 채점하거나 덱을 끝낼 때 효과음이 재생됩니다.
  - **정답음**: '좋음'으로 답할 때
  - **오답음**: '다시'로 답할 때
  - **박수 소리**: 덱 학습을 모두 끝냈을 때 (약 5초간 재생된 뒤 자연스럽게 잦아듭니다)
  - **낙담 소리**: 카드가 leech가 되거나, '다시'·'어려움'을 5번 연속 누적했을 때
- **효과음 켜기/끄기 설정**: 설정 > 학습 > 효과음에서 전체를 한 번에, 또는 정답·오답·박수·낙담 소리를 각각 개별적으로 켜고 끌 수 있습니다. (기본값: 켜짐)

## 기타

- 최신 upstream(AnkiDroid) 변경사항을 반영했습니다.
