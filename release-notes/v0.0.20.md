# v0.0.20

## 개선

- **"오래된 순" 정렬에서 오늘 학습할 카드가 없는 덱은 아래로 내려가요**: 지금까진 마지막 학습 날짜만 보고 순서를 정해서, 오늘 풀 카드가 하나도 없는 덱도 "13일 전"처럼 오래됐다는 이유만으로 목록 맨 위에 올라왔어요. "오래된 순"은 밀려서 카드가 쌓인 덱부터 처리하려고 쓰는 정렬인데 정작 할 일이 없는 덱이 자리를 차지했던 거예요. 이제 오늘 학습할 카드가 남은 덱이 먼저 오고(그 안에서는 기존처럼 오래된 순), 오늘 할 게 없는 덱은 그 아래로 내려가요. 하위 덱에 카드가 남아 있으면 상위 덱도 위쪽에 그대로 남고, 오늘 한도를 다 채운 덱은 "할 게 없는" 덱으로 봐요. "최신 순" 정렬은 그대로예요.

## 업스트림 동기화

AnkiDroid 최신 upstream 변경사항을 반영했어요. 눈에 띄는 것들:

- 음성 읽기(TTS)가 여러 엔진을 함께 인식하고, 각 음성이 속한 엔진으로 재생돼요.
- 알림 설정에서 시스템 알림 설정 화면으로 바로 이동할 수 있고, 알림 채널이 꺼져 있으면 문제 해결 화면에 표시돼요.
- 화이트보드에서 어두운 색 브러시를 골라도 선택한 색조가 보이도록 고쳤어요.
- 필터 덱에서 잘못된 검색어로 검색할 때 발생하던 오류 메시지 크래시를 고쳤어요.
- 번역이 최신화됐어요.
