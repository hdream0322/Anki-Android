# v0.1.24

최신 AnkiDroid 변경사항을 반영한 버전이에요. 인터넷 권한 없이도 공부할 수 있게 됐고, 자잘한 문제들을 고쳤어요.

## 새 기능

- **인터넷 권한 없이 사용**: 인터넷 권한을 꺼 둔 휴대폰에서도 앱이 열리고, 오프라인으로 카드를 공부할 수 있어요. 동기화 같은 기능에만 인터넷이 필요해요.
- **덱 고르기 개선**: 내보내기에서 덱을 고를 때 검색이 되는 덱 선택 창이 열려요. 검색어를 넣은 상태도 그대로 유지돼요.

## 버그 수정

- 프로필을 여러 개 쓸 때 화이트보드 같은 덱 설정이 다른 프로필로 넘어가던 문제를 고쳤어요.
- 태블릿 옆 패널에서 필터 덱을 비우거나 다시 만들 때, 엉뚱한 덱에 적용될 수 있던 문제를 고쳤어요.
- 덱 목록이 새로고침될 때 접어 둔 덱이 다시 펼쳐지던 문제를 고쳤어요.
- 화이트보드에서 지우개 동작이 중간에 끊기면 그린 내용이 사라지던 문제를 고쳤어요.
- 미리보기에서 일부 빈칸 카드가 열리지 않던 문제를 고쳤어요.
- 홈 화면 위젯이 컬렉션을 열 수 없을 때 앱이 멈추던 문제와, 처음 설치 직후 노트 추가 위젯이 동작하지 않던 문제를 고쳤어요.
- 컬렉션을 내보낸 뒤에도 백업 알림이 바로 다시 뜨던 문제를 고쳤어요.

## 업스트림 동기화

- 최신 upstream 변경사항을 반영했어요. 카드 화면을 띄우는 시스템 구성요소가 너무 오래된 휴대폰에서는 업데이트 안내가 나올 수 있어요.
- 번역이 최신화됐어요.
