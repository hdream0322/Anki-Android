# v0.1.6

학습 화면 진행률 바의 반짝임 속도를 고를 수 있고, 잔디밭 히트맵이 Anki의 하루 기준(새벽 4시)에 맞게 날짜를 세요.

## 새 기능

- **진행률 바 반짝임 속도**: 학습 화면 위쪽 진행률 바가 반짝이는 속도를 나무늘보 / 느리게 / 보통 / 빠르게 / 초고속 중에서 고를 수 있어요. 설정 → 유용한 기능 → 리뷰어에서 바꿀 수 있고, 기본값은 지금과 같은 '보통'이에요.

## 버그 수정

- 잔디밭 히트맵(덱 화면과 홈 화면 위젯)이 자정을 기준으로 날짜를 나누던 문제를 고쳤어요. 이제 새벽 4시 전에 한 학습은 전날 학습으로 표시돼요.
- 자정부터 새벽 4시 사이에 학습하면 잔디에 바로 표시되지 않고 연속 학습일이 끊긴 것처럼 보이던 문제를 고쳤어요.
